Collector example

This file is not linked from naijei.com, and the snippet below is not running. Copy it into a site only after you choose to opt in. The script does nothing unless enabled is exactly true. It loads as a module, sends one bounded page event, and ignores its own failures. 

<script type="module">
  import { install } from './collect.js'
  install({
    enabled: true,
    endpoint: 'https://admin.naijei.com/api/collect',
    key: 'REPLACE_WITH_INGEST_KEY',
    hosts: ['naijei.com', 'www.naijei.com']
  })
</script>

Use one snippet per document. A page on naijei.com/gnarly is counted as Gnarly from its path, so the main site and Gnarly should not both send the same view. The ingest key can only submit events. It cannot read the dashboard.
